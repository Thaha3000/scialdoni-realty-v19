## Deploy

1. Extract this ZIP and upload **all files** from the `scialdoni-realty-v19` folder together, at the website's public root. Do not upload only the HTML or only the photos. Alternatively, create a **new GitHub repo** `scialdoni-realty-v19`, upload all files to the repo root, and enable Pages from `main` / `(root)`.
2. Preview at `https://thaha3000.github.io/scialdoni-realty-v19/index.html` after publishing. The link is not live until GitHub Pages deployment.
3. When deploying to the official domain, Zack should change canonical/OG URLs to the official `https://scialdonirealty.com/` address, without disturbing mail DNS or nameservers.
4. After upload, hard-refresh the website and check all agent cards, Philip and Edward biographies, booking link, MLS search, contact form, and responsive navigation. A live submission and email receipt cannot be checked offline.

Security note: Never include domain/email passwords in public website files.
